## What's inside

- **No framework, no build step.** One `index.html`, one `styles.css`, one `main.js`.
- **Frontend / backend toggle.** The hero, summary and project write-ups switch between a frontend and a backend angle on the same work.
- **Terminal-flavoured sections** (`$ git log --career`, `$ ls ./selected-work`) and a small design-token panel.
- **Type:** Newsreader italic for display, Bricolage Grotesque for everything else.
- Resume PDF in [`assets/`](assets/).

## Run it locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server
```

## Deploy

GitHub Pages from `main`, custom domain via [`CNAME`](CNAME).
